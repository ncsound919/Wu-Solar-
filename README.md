## 🎯 Project Overview

Wu-Tang Solar System is an innovative edutainment platform that maps the Wu-Tang Clan members to the solar system, creating an interactive learning experience that bridges hip-hop culture, planetary science, and systems psychology.

### The Synergy Formula

```
Synergy = (Individual Strength) × (System Integration) × (Gravitational Coherence)
```

This platform teaches that just as the Sun holds planets in orbit through gravitational force, strong leadership (RZA) creates the coherence that allows diverse talents to work together without collision.

## ✨ Features

### The Four Chambers

#### 1. 🌟 Gravitational Coherence Engine
**Physics Simulator: Orbital Mechanics & Leadership Dynamics**

- Interactive 3D solar system visualization with RZA as the Sun
- Adjustable gravity parameters to demonstrate system stability
- Real-time orbital calculations showing how leadership affects group dynamics
- Learn how reducing "gravitational coherence" leads to system collapse

**The Science:** The Sun contains 99.8% of the solar system's mass. Without its gravity, planets drift into the void.

**The Wu-Tang Method:** RZA's vision and production created the gravitational pull that kept 9 distinct members in stable orbit.

#### 2. 🎤 Lyrical Density Scanner
**Linguistics & Geology: Rocky Planets vs Gas Giants**

- Text analysis tool to measure lyrical density vs atmospheric content
- **Mercury Mode (GZA)**: Analyze dense, scientific, iron-core lyrics
- **Neptune Mode (ODB)**: Measure chaotic, supersonic, atmospheric flow
- Visualization of density metrics and word analysis

**The Science:** Mercury has a massive iron core (dense, compact). Neptune has supersonic winds at 1,500 mph (chaotic energy).

**The Wu-Tang Method:** Compare GZA's stripped, scientific precision to ODB's unpredictable, high-energy chaos.

#### 3. 🛡️ Atmosphere & Shielding Builder
**Ecology & Emotional Intelligence**

- **Venus Mode (Method Man)**: Build brand atmosphere that traps attention
- **Mars Mode (Ghostface Killah)**: Navigate vulnerability and emotional exposure
- Interactive sliders to adjust charisma, mystique, rawness, and storytelling depth
- Real-time feedback on brand visibility and emotional impact

**The Science:** Venus's atmosphere traps heat (greenhouse effect). Mars lost its magnetic shield, exposing its scarred surface.

**The Wu-Tang Method:** Method Man's charisma creates a greenhouse effect of attention. Ghostface's vulnerability creates beautiful, scarred storytelling.

#### 4. 💾 Time Capsule Archive
**Data Preservation & History: The Flood Event Mini-Game**

- Interactive game simulating the 1990s basement flood that destroyed 160 floppy discs
- Race against time to digitize and save Wu-Tang history
- Learn about entropy, data loss, and preservation
- Based on RZA's real "Time Capsule" project for the Final Chamber tour

**The Science:** Entropy dictates that systems degrade over time. Data loss is a modern extinction event.

**The Wu-Tang Method:** The flood destroyed Inspectah Deck's original *Uncontrolled Substance* album, teaching the importance of preservation.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ncsound919/Wu-Solar-.git
cd Wu-Solar-
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## 📊 Data Models

### Planet/Member Mapping

Each planet is mapped to a Wu-Tang Clan member with:
- **Scientific Traits**: Composition, atmosphere, key features
- **Cultural Traits**: Style, role, lesson focus
- **Visual Properties**: Color, size, orbit parameters

Example:
```json
{
  "name": "Mercury",
  "member": "GZA",
  "scientificTraits": {
    "composition": "Iron core - extremely dense",
    "keyFeatures": ["Closest to the Sun", "Massive iron core", "Dense, compact"]
  },
  "culturalTraits": {
    "style": "Dense, scientific, intellectual",
    "lessonFocus": "Density vs Atmosphere"
  }
}
```
