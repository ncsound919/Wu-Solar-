# Contributing to Wu-Tang Solar System

Thank you for your interest in contributing! This project bridges science education and cultural studies, so we welcome contributions from diverse backgrounds.

## Code of Honor

All contributions must cite sources:
- **Scientific facts**: Link to NASA, peer-reviewed papers, or authoritative scientific sources
- **Cultural facts**: Link to verified interviews, official discographies, or reliable historical sources
- **No speculation**: Stick to documented facts and cite your sources

## How to Contribute

### 1. Educational Content

- Add new planetary science facts to `src/data/planets.json`
- Create additional lesson content
- Improve scientific explanations
- Add cultural context (with citations)

### 2. Features

- New interactive visualizations
- Additional mini-games
- Accessibility improvements
- Performance optimizations

### 3. Bug Fixes

- Report bugs via GitHub Issues
- Include steps to reproduce
- Suggest fixes if possible

## Development Workflow

1. Fork the repository
2. Create a feature branch with Wu-Tang slang naming:
   ```bash
   git checkout -b feature/protect-ya-neck-accessibility
   git checkout -b fix/bring-da-ruckus-mobile-layout
   ```

3. Make your changes
4. Test thoroughly:
   ```bash
   npm run dev
   npm run build
   ```

5. Submit a Pull Request with:
   - Clear description of changes
   - Educational value explanation
   - Source citations
   - Screenshots if UI changes

## Code Style

- Use TypeScript for type safety
- Follow existing patterns in the codebase
- Add comments for complex logic
- Keep components focused and reusable

## Educational Guidelines

### "Each One Teach One"

The goal is education. Write code and documentation that students can learn from:

- Explain complex concepts simply
- Use clear variable names
- Add comments that teach, not just describe
- Link to educational resources

### Accuracy

- Scientific accuracy is paramount
- Cultural representation must be respectful and factual
- Cite sources for all claims

## Questions?

Open a GitHub Discussion or Issue. We're here to help!

## Recognition

Contributors will be recognized in:
- README acknowledgments
- Project documentation
- GitHub contributors page
